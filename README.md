# civos · Civilization OS Ecosystem · 文明操作系统生态

A unified specification for ten interlocking civilization-scale subsystems. This repository is the **hub** — architecture, shared ontology, dependency graph, and the global API index.

Each of the ten subsystems is independently deployed at its own subdomain:

| Subdomain | System |
|-----------|--------|
| civilization-os.psyverse.fun       | Civilization OS — macro civilization model |
| idea-evolution.psyverse.fun        | Idea Evolution — memetics & ideology propagation |
| material-civilization.psyverse.fun | Material Civilization — atoms → energy → industry |
| psy-protocol-spec.psyverse.fun     | Psy Protocol — the wire (proofs, state roots) |
| clan-civilization.psyverse.fun     | Clan Civilization — kinship & trust networks |
| sensory-os.psyverse.fun            | Sensory OS — perception as predictive inference |
| reality-kernel.psyverse.fun        | Reality Kernel — physics, thermo, computation |
| decision-os.psyverse.fun           | Decision OS — game theory + AI + economics |
| cycle-engine.psyverse.fun          | Cycle Engine — historical & systemic phases |
| life-os.psyverse.fun               | Life OS — biological computation stack |
